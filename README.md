# Internship Matchmaking System (IMS)

The **Internship Matchmaking System (IMS)** is an Android application developed using **Java**, **SQLite**, and **Android Studio** to simplify the internship recruitment process. It provides a centralized platform where students can create professional profiles, browse internship opportunities, apply for positions, and track their applications. Organizations can post internship openings, review applicants, and manage recruitment efficiently through the same platform.

The system replaces manual internship coordination with a secure and user-friendly mobile solution, improving communication, transparency, and accessibility for both students and recruiters.

---

## Features

- Student registration and profile management
- Organization registration and authentication
- Internship posting and management
- Internship search and application
- Algorithms to recommend mathing internships to students and interns to organizations
- Application status tracking
- Internship request management
- Secure local data storage using **SQLite**
- User-friendly Android interface

---

## Tech Stack

- **Java**
- **Android Studio**
- **SQLite**
- **XML**
